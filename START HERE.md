# Sasol jumpstarts: setting them up

Three governed reviews, each a Claude plugin with its own Claude project and project folder. Each folder here is one use case, with its own **START HERE.md**.

| Use case | Version |
|---|---|
| Early Payment Detection | 1.10.0 |
| Duplicate Vendors & Payments | 1.10.0 |
| Contract & Spend Leakage | 1.10.0 |

**First, the plugins.** Upload the three zips in `Plugins to upload` in the Claude app: **Customize → Plugins → Add → Upload plugin**, one at a time, leaving each zip as it is. No GitHub access is needed. (Each START HERE.md also gives the catalogue route, which keeps them up to date through GitHub.) Then, for each use case, copy its project folder (step 2) and create its Claude project (step 3).

All the data in these packages is invented. Never use real Sasol data.
