# Contract & Spend Leakage

This folder holds the files for the contract-leakage review. Every review uses the same structure, so each one finds its files in the same place.

| Folder | What it holds | Written by |
|---|---|---|
| `01 Documents` | The panel agreements (Word) | People. The review only reads it |
| `02 Data` | The spend history and the invoice lines (Excel) | People. The review only reads it |
| `03 Outputs` | A folder for each review: **Report** (the dashboard report, the management briefing, the presentation and the one-page summary), **Evidence** (the evidence pack, the audit trail and the data, row by row) and **Actions** (any drafts) | The review, only after a second person approves the release |
| `04 Records` | The record of each review: every step, decision and approval, in a tamper-evident form | The review, when it's released |

Keep the folder names as they are. To confirm that a record hasn't been changed, ask in the project: *"Can we check the record hasn't been changed?"*
