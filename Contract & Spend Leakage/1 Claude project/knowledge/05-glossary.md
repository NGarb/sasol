# Glossary

| Term | Meaning here |
|---|---|
| **Panel agreement** | An agreement with approved suppliers for a category, with its own reference |
| **Contract reference** | The agreement a purchase order was raised under; blank if none |
| **Contract register** | The agreements the purchases quote, whether or not they're in the project folder |
| **Not on file** | An agreement the purchases quote that isn't among the documents, so its terms can't be checked |
| **Contracted category** | A category a contract covers: its purchases quote an agreement read in this review, or one relied on from the register |
| **Off contract (definition A)** | Every purchase with no contract reference |
| **Off contract (definition B)** | Purchases with no contract reference in a contracted category: the recommended reading |
| **Hotspots** | The three categories with the most off-contract spend |
| **The card** | The one form where a person makes every decision the review needs, with a reason for each, their full name and their role |
| **Commencement date** | When the agreement started; its anniversary is the day a yearly rate adjustment may apply |
| **Initial term / renewal period** | How long it first runs, and how long each automatic renewal lasts |
| **Notice deadline** | The last day to give notice so the agreement doesn't renew: the end of the current period, less the notice days the agreement requires |
| **Review date** | The day the review started: every notice deadline is counted from it |
| **Rate notice** | A supplier's written notice of an adjusted rate, required before it takes effect, and valid only when delivered to the contracts office |
| **CPI allowed** | Statistics South Africa's published headline CPI, annual change, for the second month before the month of the notice |
| **No notice / Notice outside the terms / Late notice / Before the anniversary / Above CPI** | The five kinds of rate rise outside an agreement's terms |
| **Charged above the terms** | What was charged above the rate allowed, invoice line by invoice line |
| **Claim / accept / refer** | The choices for each rise outside the terms: a credit note, nothing, or a decision elsewhere |
| **Measured / assumed** | The two parts of the projected gain: credit notes and paying the agreed rate, and buying on contract at the assumed 5% saving |
| **Drafts** | Notice letters, rate queries, requests for agreements and a referral note, for a person to review, sign and send |
| **Approval to release** | A second person's approval, in a release role, before findings go anywhere |
| **Fingerprint** | A short code that changes if the figures change: proof of exactly what was seen or approved |
| **Tamper check** | Confirms the record of the review hasn't been edited, removed or reordered |
